# Discord Quest Auto-Completer

Automatically completes Discord Quests and helps you claim their rewards.

## Installation & Usage

1. Install **Vencord** for Discord.
2. Restart your computer after installation.
3. Open **Discord**.
4. Press **`Ctrl + Shift + I`** to open Developer Tools.
5. Go to the **Console** tab.
6. Copy the code from the provided **`.js` file** and paste it into the console.
7. Run the script and press **Enter**.

## How It Works

After starting the script, available Discord Quests are completed automatically.

The script handles the required quest progress, including supported promotional/ad-related tasks, so you don't have to complete them manually.

Once a quest is completed, its available reward can be claimed.
